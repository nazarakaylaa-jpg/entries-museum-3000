One line: the museum label a museum in the year 3000 puts beside a parking meter. One line, deadpan, deterministic — the program writes it to `/output/entry.txt` on every run. Node 22, standard library only.

## The line

```
Parking meter, c. 2025. Coin-fed altar. Citizens fed it metal discs and prayed their vehicle would stay. The prayer usually failed.
```

131 characters. The year 3000 misreads the meter as a coin-fed altar: citizens fed it metal discs and prayed their vehicle would stay — and the prayer usually failed, because the vehicle was still taken. The joke is the misreading itself, stated as a flat catalogue fact.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
